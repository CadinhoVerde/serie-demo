# Série — Demo Labsites

Demonstração pública independente de musculação e boxe, com dados inteiramente fictícios. HTML, CSS e JavaScript, sem servidor ou dependências.

## Executar
Sirva a pasta `public` com um servidor HTTP estático. Na Vercel, framework Other, sem build e diretório de saída `public`.

## Experimentar
Registre séries, compare com a semana anterior, edite ciclos e experimente a luta rápida (55 segundos) ou o cronômetro real (11 minutos). Restaurar demo remove somente as chaves desta demo no navegador. Não existe sincronização entre visitantes.

## Separação
Este repositório não inclui PDFs, dados reais, histórico Git ou configuração de hospedagem do aplicativo pessoal. As chaves de armazenamento começam com `labsites-serie-demo-`. Não é uma prescrição de treino.
